🔗 Setup Garmin MCP Server

Sambungkan dashboard ke data Garmin Connect Anda secara real-time menggunakan MCP server.

1
Install garmin_mcp via pip
Buka terminal dan jalankan:
pip install garmin-mcp
2
Konfigurasi Claude Desktop
Tambahkan ke file claude_desktop_config.json:
{ "mcpServers": { "garmin": { "command": "uvx", "args": ["garmin-mcp"], "env": { "GARMIN_EMAIL": "email@anda.com", "GARMIN_PASSWORD": "password_anda", "GARMIN_ENABLED_TOOLS": "get_steps_data,get_sleep_data,get_heart_rate_data,get_stress_summary,get_activities,get_training_readiness" } } } }
3
Atau gunakan .dxt (Claude Desktop Extension)
Download garmin-mcp.dxt dari halaman Releases dan drag ke Claude Desktop.
4
Update data di dashboard ini
Setelah MCP terhubung, minta Claude untuk mengambil data dan mengisi objek DATA di bagian script HTML ini.
